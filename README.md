## Thoughts on the article
This article discusses how hiring companies are looking for more cerebral approaches to their hiring processes due to the involvement of AI in the industry. While technical skills are still needed to get a job, the question now is if you can use those skills to actually produce something. What I find interesting about this is that for new grads, skills alone aren't able to find a job, but the bar is higher. Candidates for entry level jobs now must know how to write code, put that towards a specific issue, and especially now, know how to collaborate with AI. While I think this is a reasonable expectation of raising the bar on the profession, there is the other side that jobs are no longer interested in investing in someone based on a strong technical basis. The shifting expectation now seems to be for companies to be able to hire a "ready-made" candidate who will require less time to be useful for the company. The question is whether these requirements will keep rising or will they eventually plateau as entry level candidates can only learn so much before getting these jobs.
